Understanding the CSS Box Model

This page demonstrates the foundational principles of CSS and the Box Model through practical examples.

The Content Box

This is the innermost part of the Box Model. It's where your text, images, and other content live. The dimensions of this box are defined by an element's width and height properties.

Padding

Padding is the transparent space directly surrounding the content. It acts as a buffer between the content and the element's border, and it takes on the element's background color.

Border

The border is a line that goes around the padding and the content. It's the visible edge of the box and can be styled with properties like `color`, `style`, and `width`.

Margin

Margin is the transparent space outside the border. It pushes other elements away from the box, creating separation between different elements on the page.
